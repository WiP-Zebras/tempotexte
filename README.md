# TempoTexte

Estimateur statique de temps de lecture, exécuté entièrement dans le navigateur.

## Développement

```sh
npm run build
npm run dev
```

Puis ouvrir <http://localhost:4173>.

`npm test` lance les tests métier. Les tests initiaux décrivent le contrat du moteur avant son implémentation.

## Publication

Le dossier `docs/` est la copie publiable pour GitHub Pages depuis une branche. Aucun workflow GitHub Actions n’est requis.
